# 授權條款

VMark 以 **ISC 授權條款** 發布 — 最簡單、最寬鬆的開放原始碼授權條款之一，功能上等同於 MIT。

## ISC 授權條款允許的事項

- **使用** — 用於任何目的，商業或個人
- **複製** — 自由散布
- **修改** — 按你的意願更改程式碼
- **散布** — 分享你修改後的版本

## 它的要求

- 在副本中保留版權聲明和許可聲明

## 它不做的事項

- 提供任何保證 — 軟體以「現狀」提供
- 讓作者對損害負責

## 為什麼選擇 ISC？

ISC 授權條款在功能上等同於 MIT 授權條款，但語言更簡單。它獲得[開放原始碼倡議（OSI）](https://opensource.org/licenses/ISC)批准，是 npm 和 OpenBSD 使用的預設授權條款。

選擇它作為 VMark 的授權條款是因為：

- **簡潔** — 易於閱讀和理解
- **寬鬆** — 對軟體使用方式沒有限制
- **相容性** — 與幾乎所有其他開放原始碼授權條款相容

## 第三方軟體

VMark 建立在眾多作者的開源軟體之上：Rust crate、npm 套件，以及編譯進這些套件中的元件，例如 Graphviz 和 MCP 伺服器內建的 Node.js 執行環境。它們的授權條款（MIT、Apache-2.0、BSD、ISC、MPL-2.0、EPL-2.0 等）要求每一份 VMark 副本都附上相應的聲明。

每個 VMark 建置都包含這些聲明的完整文字。要閱讀它們，請開啟 **設定 → 關於**，然後點選 **第三方聲明**，檔案會在預設的文字檢視器中開啟。

這些聲明依據每個版本的確切相依套件產生，因此與你安裝的版本一致。
