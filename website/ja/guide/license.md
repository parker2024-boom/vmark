# ライセンス

VMark は **ISC ライセンス** — 最もシンプルで許容的なオープンソースライセンスの一つで、機能的には MIT と同等 — の下でリリースされています。

## ISC ライセンスが許可すること

- **使用** — 商業目的または個人目的を問わず
- **コピー** — 自由に配布
- **修正** — 自由にコードを変更
- **配布** — 修正したバージョンを共有

## 求められること

- コピーに著作権表示と許可表示を保持すること

## 行わないこと

- いかなる保証も提供しない — ソフトウェアは「現状のまま」提供されます
- 損害に対して著者に責任を負わせない

## なぜ ISC なのか?

ISC ライセンスは MIT ライセンスと機能的に同等ですが、よりシンプルな言語を使用しています。[オープンソースイニシアティブ（OSI）](https://opensource.org/licenses/ISC)によって承認されており、npm と OpenBSD で使用されるデフォルトのライセンスです。

VMark 向けに選ばれた理由:

- **シンプルさ** — 読みやすく理解しやすい
- **許容性** — ソフトウェアの使い方に制限なし
- **互換性** — ほぼすべての他のオープンソースライセンスと互換性がある

## サードパーティ製ソフトウェア

VMark は多くの作者によるオープンソースソフトウェアの上に作られています。Rust のクレート、npm パッケージ、そしてそれらに組み込まれてコンパイルされたコンポーネント（Graphviz や MCP サーバー内の Node.js ランタイムなど）です。これらのライセンス（MIT、Apache-2.0、BSD、ISC、MPL-2.0、EPL-2.0 など）は、VMark のすべての複製にその通知を添えることを求めています。

VMark のすべてのビルドには、これらの通知の全文が含まれています。読むには **設定 → このアプリについて** を開き、**サードパーティ通知** をクリックします。ファイルは既定のテキストビューアで開きます。

通知は各リリースの正確な依存関係から生成されるため、インストールしているバージョンと一致します。
